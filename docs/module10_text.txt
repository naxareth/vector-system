Main Task: Identify & Plan
1. Identify the Bottleneck
Review your monitoring table from Session 1. Choose one clear performance issue (e.g., slow API call or high gas cost).
The "Long Input" test case — parsing and validating a 500-row CSV batch took ~1.8 seconds and briefly froze the browser UI during Zod schema validation.

2. Define Your Fix
Write one sentence describing exactly how you will solve it.
Offload the synchronous CSV validation loop to a Web Worker so that Zod schema parsing runs off the main thread, preventing UI freeze during large batch uploads.

3. Get Approval
Show your written plan to your teacher before writing any code.

Root Cause Analysis
What made that case slow or costly?
The CSV parser runs synchronously on the main JavaScript thread. For 500 rows, each row triggers Zod .safeParse() with regex-based UUID and Ethereum address validation, plus formula injection sanitization — all blocking the event loop.
