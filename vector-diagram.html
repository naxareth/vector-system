6 Same mint — course generation Gemini API (fire & forget) courses table title, provider, link, skill_tags[] Only runs for uncovered tags. Never blocks mint response.
7 Daily cron runs GitHub Actions → daily-update.ts market_snapshots keyword, job_count, avg_salary, location_data, recorded_at Adzuna API. One snapshot per keyword per day.
8 After snapshots inserted decay-forecaster.ts skill_health_cache skill_name, health_score, trend_label, velocityScore, confidence, avg_salary, top_locations 3-signal: slope 40% + volume 30% + recency 30%
9 Student loads /student/coach POST /api/analyze skill_health_cache (read) + courses (read) studentId, skillsOverride[] Returns skillHealth[], history[], recommendations[], atRiskSkills[]
10 Student sends chat message POST /api/chat Gemini API message, context (skills, salary, location, recommendations) Salary + location injected as context. GEMINI_API_KEY_CHAT (Phase 13c).
11 Student exports CVR POST /api/cvr/export cvr_exports user_id, template, credential_ids[], snapshot (full CVR JSON) Returns UUID. Immutable — never updated after insert.
12 Employer scans QR GET /api/verify/cvr/[id] cvr_exports (read) UUID → full CVR snapshot Public, no auth. isLatest flag warns if newer export exists.
13 Student analyzes CVR POST /api/cvr/analyze Gemini API + skill_health_cache CVR snapshot enriched with market data Returns overallScore, skillStrength[], marketAlignment, missingKeywords[], recommendations[]
14 Credential public verify GET /api/verify/[id] verified_credentials + Polygon Amoy credential id → W3C JSON-LD + on-chain token check No auth required. Used by QR scanner and notification link_url.
15 Skill extractor F1 eval evaluate-extractor.ts (manual) Gemini API → golden-dataset.json 20 credential titles → extracted skill tags F1: 0.61, P: 0.62, R: 0.60. SOFT match. 13s delay for 5 RPM.

Key Architectural Decisions
Zero-Shot NLP Gemini extracts skills from any credential type on first mint with no retraining. Handles TESDA vocational certs, DICT government certs, academic degrees equally. Solves concept drift by design — new domains work immediately.
No ARIMA ARIMA requires 30+ time series data points for statistical validity. Current data density insufficient. Recency-weighted velocity scoring (slope 40% + volume 30% + recency 30%) is statistically appropriate now. ARIMA documented as upgrade path after 6-12 months.
No Cross-Package Imports Turbopack cannot resolve relative paths across packages. All ai-engine logic used in web portal is inlined (generateCoursesForTag). Each package has its own Gemini client instance.
Service Role for Notifications Supabase anon key respects RLS — registrar cannot write to student's notifications row. supabaseAdmin (service role) bypasses RLS for the notification insert only. Realtime subscription on student side delivers instantly via websocket.
